# PR Agent — Stub

**Status: Stub only. Not implemented.**

This document describes what a real PR agent would do. The pipeline script prints this summary instead of executing it.

---

## What a Real PR Agent Would Do

### Step 1 — Create feature branch
```bash
git checkout -b analytics/auto/{model_name}_{timestamp}
# e.g. analytics/auto/gold_package_downloads_daily_20260515
```

### Step 2 — Commit generated output
```bash
git add generated_output/gold_package_downloads_daily.sql
git add generated_output/gold_package_downloads_daily.yml
git commit -m "feat: auto-generate gold_package_downloads_daily

Analyst request: {analyst_request_summary}
Generated by: run_pipeline.py
Review result: PASS (0 blocking errors, {n} warnings)
"
```

### Step 3 — Open GitHub PR
```bash
gh pr create \
  --title "Auto: gold_package_downloads_daily" \
  --body "$(cat pr_body_template.md)" \
  --assignee {requesting_analyst} \
  --label "auto-generated" \
  --label "needs-human-review"
```

### Step 4 — Notify analyst
- Comment on PR: "Your model draft is ready for review. Review report: [link]."
- Optional: post to Slack via MCP server (see `docs/mcp_integrations.md`).

---

## Why It Is Stubbed

- Requires a GitHub token and repository write access — an external integration dependency.
- The assignment explicitly permits stubbing tool integrations.
- The value of this pipeline is in the agent logic and prompt quality, not in the GitHub API call.

---

## What Would Be Needed to Implement It

| Requirement | Detail |
|---|---|
| GitHub token | `GITHUB_TOKEN` env variable with repo write scope |
| `gh` CLI or PyGithub | For PR creation |
| Slack webhook (optional) | For analyst notification |
| Branch naming convention | `analytics/auto/{model}_{date}` |
| PR template | Standard body referencing analyst request + review report |

---

## Human-in-the-Loop Requirement

Even with a real PR agent, a human must review and approve the PR before merge. The pipeline is designed to produce a reviewable draft, not to auto-merge. The review agent's output is a starting point for human judgment, not a replacement for it.
